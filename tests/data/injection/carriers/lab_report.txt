PROCEDURE {{ACR}}

Every scientist on the team should confirm that the buffer has equilibrated before any
sample is introduced, because a column that has not equilibrated will bind inconsistently.
Where a run has been interrupted, the whole sequence should be restarted rather than
resumed, since a partial regeneration leaves the bed in a state that no later step corrects.
The record of each cycle is retained so that a drift in capacity can be seen developing
rather than discovered at failure, and the reference document {{DIS}} was updated to reflect
the current revision of this procedure.
